# Элементы для светлой презы «Системная работа с талантами» (ХГ 2026)

Эти элементы заменяют декор Юли, сделанный под тёмный дизайн: сердце, роботов, девушку, мозг, руку и голубые ступени. Фото и скриншоты не трогаем, они остаются как есть.

Стиль тот же, что у пакета «Элементы през гейма»: светлая пастель, матовое стекло, глянцевый белый и фирменный красный пластик, 3D «игрушечного» вида. Поэтому продолжай в **том же чате ChatGPT**, где делался пакет. Если чат новый, сначала приложи референсы из `Элементы през гейма/00_Референсы` и вставь оттуда **Блок 0** из мастер-файла. После этого вставь блок ниже.

Готовые PNG клади в `assets/gen/` с именами строго как в списке. Сборщик сам подставит их вместо старых картинок и пересоберёт слайды.

Проверка каждой картинки:
- фон прозрачный;
- нет букв, цифр и логотипов;
- объект целиком в кадре, вокруг есть воздух;
- никаких тёмных фонов и хрома.

## БЛОК ХГ. Элементы для презы «Системная работа с талантами»

```
Блок ХГ. Новые элементы в том же стиле пакета, правила те же: прозрачный фон, без текста, букв и цифр, мягкий свет сверху слева, белый глянец + фирменный красный #EF3124, матовое стекло с розово-лавандовым отсветом, игрушечные скруглённые формы. Никаких тёмных фонов, хрома, неона и реалистичных людей. Генерируй по одному, по списку, имя файла подписывай.

1. hero_kristall_garnitura.png — 1024×1024. Герой обложки «Хрустальная гарнитура»: большая гарнитура оператора (дуга-оголовье, две чашки, микрофон на гибкой ножке) целиком из прозрачного матового хрусталя с радужно-розовым отливом и мягкими бликами. Внутри левой чашки светится маленькое глянцевое красное сердце. Вид три четверти чуть сверху, гарнитура слегка наклонена. Вокруг 3–4 мелкие стеклянные искры. Объект крупный, занимает ~80% кадра.

2. ai_nastavnik_robot.png — 1024×1024. Дружелюбный робот-помощник по пояс: округлая белая глянцевая голова-капсула, лицевая панель из тёмно-лавандового стекла с двумя простыми светящимися глазами-дугами (улыбается глазами), красные акценты на ушах-наушниках и на груди, короткие скруглённые руки. Машет правой рукой. Это AI-наставник, он всегда рядом. Без надписей и экранов с текстом.

3. ai_robot_kniga.png — 1024×1024. Тот же самый робот из пункта 2 (строго тот же дизайн), в рост, сидит и держит раскрытую книгу с красной обложкой, из книги растёт маленький зелёный росток. Это рекомендации, которые помогают сотруднику расти.

4. ai_sotrudnik.png — 1024×1024. Фигурка-бюст сотрудника контактного центра в стиле иконок пакета (как ic_srv_klient): гладкая белая фигурка без лица, красный ворот, на голове белая гарнитура с красным микрофоном. Рядом парят два маленьких стеклянных облачка чата, белое и розовое, с тремя точками.

5. ai_mentor_yadro.png — 1536×1024. AI-ментор как «ядро»: глянцевая белая сфера с мягким красным свечением изнутри и тонкими светящимися красными линиями-нейронами по поверхности. Вокруг сферы по орбите парят 4 маленькие стеклянные карточки-плашки (пустые, с абстрактными полосками), маленькая кнопка «плей» и наушники. Это генерация персонального контента. Объект по центру, по бокам воздух.

6. ai_ruka_robota.png — 1536×1024. Белая глянцевая рука робота с красными шарнирами тянется из левого нижнего угла вверх-вправо, указательным пальцем касается парящей стеклянной карточки (пустая, с абстрактными полосками и маленькой красной галочкой). Это AI-экзаменатор, который проверяет и подтверждает. Рука обрезана только краем кадра слева внизу, всё остальное целиком.

7. karera_stupeni.png — 1536×1024. Три широкие ступени из матового стекла поднимаются слева направо. На нижней ступени две белые руки в рукопожатии (наставник), на средней пухлая золотая звезда (кадровый актив), на верхней белое кресло руководителя с маленькой золотой короной над спинкой. Между ступенями пунктирная дорожка из красных точек. Вид три четверти, мягкий розово-лавандовый отсвет. Ступени без цифр и надписей.
```
