# Промты для ChatGPT: картинки для презы

Акцентный цвет презы теперь фиолетовый: **#5B3BE8**. Светлый оттенок: **#A68EFF**, фон пастельный, розово-сиреневый.
Красного в презе больше нет. Красный остался только в логотипе банка и на нескольких фотографиях (см. промт 3).

**Как вставлять.** Правой кнопкой по картинке → «Изменить рисунок» → «Из файла». Если картинка встала криво: «Обрезка» → «Заливка». Скругление и размер рамки сохранятся.

## 1. Общее фото пятерых (слайд 2), самое важное

Сейчас на слайде 2 стоит **временная** картинка: кусок обложки с моделями. Её нужно заменить на ваше общее фото.

В ChatGPT прикрепляете 5 фотографий: Юля, Алина, Макс, Лариса, Лада. Лучше всего портреты по пояс с хорошо видным лицом. Пишете:

```
Сделай одно общее фото команды из пяти человек с прикреплённых фотографий.
Лица и внешность каждого человека сохрани максимально точно, не меняй черты лица,
возраст, причёски. Слева направо: Юля, Алина, Макс, Лариса, Лада.

Стиль: светлая модная корпоративная фотосессия. Все пятеро стоят рядом плечом к плечу,
дружелюбно улыбаются, смотрят в камеру, кадр по пояс (от середины бедра и выше).
Одежда в светлой гамме: белый, молочный, светло-серый; детали одежды и аксессуары
фиолетовые (#5B3BE8), никакого красного. У двоих девушек на шее лёгкие
беспроводные гарнитуры белого цвета с фиолетовыми вставками.

Фон: мягкий пастельный градиент из нежно-розового, сиреневого и голубого,
за спинами большая светящаяся глянцевая сфера розово-сиреневого цвета, мягкий
рассеянный студийный свет, лёгкие блики, глянцевый пол с отражением.
Без рамок, без текста, без логотипов.

Формат: горизонтальный, широкий, примерно 2:1. Люди по центру,
по краям немного воздуха.
```

Если общее фото выходит плохо (лица «плывут»), делайте **по одному человеку** этим промтом, а потом склейте 5 картинок в один ряд:

```
Сделай портрет человека с прикреплённого фото. Лицо сохрани точно.
Кадр по пояс, лёгкая улыбка, смотрит в камеру. Светлая одежда (белый/молочный/
светло-серый), фиолетовые детали (#5B3BE8), без красного.
Фон: пастельный градиент розовый-сиреневый-голубой, мягкий студийный свет.
Без текста и рамок. Формат вертикальный 3:4.
```

## 2. Обложка и финал с вашими лицами (слайды 1 и 15), по желанию

На обложке и финале сейчас сгенерированные модели. Если хотите, чтобы там были вы,
прикрепляете те же 5 фото и картинку текущей обложки (её можно сохранить из презы: правой кнопкой → «Сохранить как рисунок»):

```
Перерисуй прикреплённую картинку (обложку) так, чтобы пятеро людей на ней
были людьми с прикреплённых портретов. Лица сохрани точно. Композицию, позы,
фон, свет и стиль оставь как на исходной картинке.
Все красные элементы (шарф, ремни, детали гарнитур) сделай фиолетовыми #5B3BE8.
Без текста. Формат 16:9.
```

Для финала (слайд 15) то же самое, но к промту добавьте: «люди идут спиной к камере, рядом идёт белый робот — оставь его, красные детали робота тоже сделай фиолетовыми».

## 3. Убрать красное с фотографий (слайды 9, 10, 12)

На этих фото остались красные гарнитуры и полоски на одежде. Сохраняете картинку из презы (правой кнопкой → «Сохранить как рисунок»), прикрепляете в ChatGPT:

```
Замени на этой картинке все красные элементы (гарнитура, микрофон, полоски
на одежде, детали робота) на фиолетовые, цвет #5B3BE8. Всё остальное оставь
без изменений: лица, позы, одежду, свет, прозрачный фон.
Сохрани PNG с прозрачным фоном.
```

- Слайд 9: девушка-оператор в гарнитуре.
- Слайд 10: двое подростков в гарнитурах.
- Слайд 12: девушка и робот («Человек» и «ИИ»).

```
(#5B3BE8), без красного. Без читаемого текста и логотипов.
Формат квадрат 1:1.
```

## 5. Иконки (если захотите перерисовать)

Красные 3D-иконки уже перекрашены в фиолетовый прямо в файле. Если какая-то будет смотреться странно, вот промт для новой иконки в том же стиле:

```
3D-иконка: [ЧТО НАРИСОВАТЬ, например: календарь / рукопожатие / чек-лист /
кнопка play / ноутбук / пазл / замок / облако чата / открытая книга / щит с галочкой /
академическая шапочка / песочные часы / сердце / робот-помощник].
Стиль: глянцевый 3D-рендер, мягкие формы, белый и светло-серый пластик
с фиолетовыми акцентами (#5B3BE8), лёгкое стекло, мягкие тени, студийный свет.
Без текста. Прозрачный фон, PNG, квадрат 1:1.
```
