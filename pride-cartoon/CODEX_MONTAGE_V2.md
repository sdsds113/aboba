## 1. Что где лежит

| Путь | Что это |
|---|---|
| `pride-cartoon/timeline.json` | монтажный лист: 55 планов (id `S01-01`…`S09-06`), у каждого `tl_in`/`tl_out`/`dur` на таймлайне, `gen` (какой файл клипа), `clip_in` (с какой секунды клипа брать), `overlay` (надписи) |
| `pride-cartoon/scene_clips.json` | откуда берётся каждый план: `{ "S03-02": {"file": "clips/S03-02.mp4", "shots": {"S03-02": 0.3}} }`. Записи раунда 3 (ключи `Sxx-yy`) **перекрывают** старые записи `Gxx` |
| `pride-cartoon/clips/` | клипы: старые `G01…G25.mp4`, `G11b.mp4`, `G16b.mp4` и новые **37 поплановых `Sxx-yy.mp4`** (Kling 4.0, 1080p) |
| `pride-cartoon/build_storyboard.py` | применяет `scene_clips.json` к `timeline.json` (переписывает `gen`/`src`/`clip_in`) |
| `pride-cartoon/register_shots.py` | подхватывает все `clips/Sxx-yy.mp4`, пишет их в `scene_clips.json` (clip_in = 0.3, у S09-05 = 0.2) и запускает `build_storyboard.py` |

| `pride-cartoon/audio/` | `voiceover_full.mp3`, `music.mp3`, `sfx/*.mp3`, `mix.json`, `sfx_cues.json`, `offsets.json` |
| `pride-cartoon/assets/` | графика E01–E15, P01, `processed/` |
| `pride-cartoon/remotion/` | проект Remotion 4.0.540 (`src/Birthday.tsx` — главная композиция `Birthday`, 24 fps, 1920×1080) |
| `pride-cartoon/remotion/scripts/sync.mjs` | копирует клипы, аудио, графику и json из `pride-cartoon/` в `remotion/public` и `remotion/src/data` |

## 4. Команды

```bash
cd pride-cartoon
python3 register_shots.py          # подхватить клипы Sxx-yy и пересобрать timeline.json
cd remotion
npm install
node scripts/sync.mjs              # должно найти 64 клипа (27 G + 37 S)
npx remotion render src/index.ts Birthday out/birthday.mp4 --concurrency=4
```

Если рендер в Linux-контейнере падает на загрузке шрифтов (сертификаты прокси), запускай с полным Chromium:
`--browser-executable=<путь к chrome> --chrome-mode=chrome-for-testing`.

## 5. Проверка перед сдачей

1. `ffprobe out/birthday.mp4`: 1920×1080, 24 fps, длительность около 136.6 с, есть аудио.
2. Сделай стоп-кадры по одному из середины каждого плана: `tl_in + dur/2` из `timeline.json`. Проверь:
   - в синем домике (S02–S05-01) **нет** Серёжи, Кудряшова, Тани и Жени;
   - таблички «2000-е · Секвойя», «2012 · Восточный», «2019 · Альфа» видны и не обрезаны;
   - нет чужого текста или букв из генераций;
   - в S09-05 финальный кадр стоит, и S09-06 корректно уменьшает его в рамку на стене.
3. Звук: диктор слышен поверх музыки, конец ролика не обрывается.

## 6. Что не трогать

- Тексты, озвучку, музыку и тайминги планов (`tl_in`/`dur`): всё согласовано.
- `clip_in` меняй только если в начале или конце плана видна склейка или рывок. Правь в `scene_clips.json`, потом запусти `python3 build_storyboard.py`.
