МУЛЬТИК ДЛЯ ПРАЙДА — РЕНДЕР НА СВОЁМ КОМПЬЮТЕРЕ

Внутри папки всё нужное: код монтажа, все 37 новых клипов, старые клипы,
озвучка, музыка, звуки, графика.

1) Установите Node.js 22 (LTS): https://nodejs.org  (если ещё не стоит)

2) Распакуйте архив, откройте терминал В ЭТОЙ ПАПКЕ
   (Windows: в проводнике в адресной строке напишите cmd и Enter;
    Mac: правый клик по папке → «Новый терминал по адресу папки»)

3) Один раз установите зависимости:
   npm install

4) Рендер (1920x1080, ~2:17):
   npx remotion render src/index.ts Birthday out/birthday.mp4

   Готовый файл появится в папке out/birthday.mp4.
   На обычном ноутбуке 10–30 минут. Можно ускорить: добавить --concurrency=6

Посмотреть и покрутить до рендера (откроется в браузере):
   npx remotion studio src/index.ts

ВАЖНО: не запускайте «npm run dev» — эта команда ищет исходники в родительской
папке проекта и здесь не нужна. Всё уже лежит в public/.

Если ругается на шрифты/интернет — рендер подгружает шрифт Nunito из Google Fonts,
нужен интернет при первом запуске.
