# Мультик ко дню рождения — монтаж (Remotion)

Проект собран по образцу `../../montage`: те же версии Remotion и настройки. Код написан, проходит `tsc` и `eslint`. Контрольные кадры и черновой рендер с заглушками сделаны в облаке.

**Всё, что монтируется, берётся из данных:**
- `../timeline.json` — 55 планов: тайминги, точки входа в клипы, оверлеи;
- `../audio/*` — голос, музыка, эффекты, уровни микса;
- `../assets/*` — графика;
- `../clips/` — клипы из Flow.

Раньше ТЗ для Codex лежало в `../REMOTION_BRIEF.md`. Теперь монтаж делает этот проект, а Codex генерирует только сцены.

## Быстрый старт

```bash
cd pride-cartoon/remotion
npm ci
npm run dev        # sync + Remotion Studio
```

`npm run sync` (он же в `npm run dev`) копирует в `public/` голос, музыку, эффекты, графику и клипы, а в `src/data/` — JSON с таймингами. Запускать после любых изменений в соседних папках.

## Клипы из Flow

Положить в `pride-cartoon/clips/` под именами `G01.mp4` … `G25.mp4` (что в какой генерации — в `../storyboard.md`), затем `npm run sync`. План, у которого клипа нет, показывается заглушкой: тёмный фон с номером и описанием. Так можно смотреть монтаж, пока генерируются не все клипы.

Если нужный момент в клипе оказался не на той секунде, в `src/config.ts` → `CLIP_IN_OVERRIDES` поставить `{ "S03-02": 0.6 }`: с какой секунды клипа брать план.

| `src/overlays/Titles.tsx` | «Наш дом», табличка с годом (E05), плашки с именами (E06), «Семья? Клан? Династия?» с эмблемами |

## Что подставить перед финалом

1. **Имена и департаменты** — `PEOPLE` в `src/config.ts`.
2. **Годы на стене** — `label` в `../photo_wall_layout.json`. Годы на табличках S02-01 и S05-02 — `overlay.text` в `../build_storyboard.py`, после правки перезапустить `python3 ../build_storyboard.py`.
3. **Фирменный шрифт** — `src/theme.ts`.
4. **Звезда (S07-10)** — `STAR.x/y` в `config.ts`, чтобы она встала над крышей дома в реальном клипе.

## Звук

Уровни лежат в `../audio/mix.json`: `vo_gain`, `music_under_voice`, `music_no_voice`. Их же использует `../mix_preview.py`, который собирает черновой микс без видео.

## Рендер

```bash
npx remotion render Birthday out/birthday.mp4 --crf=18
```

1920×1080, 24 fps, 2:17 (3279 кадров). Отдельные композиции для проверки: `PhotoWall`, `FinalWall` (папка Scenes).

**В облачной песочнице** Chrome Headless Shell не доверяет сертификату прокси, и Google Fonts не грузятся. Рендерить там полной сборкой Chromium:
`--browser-executable=/opt/pw-browsers/chromium-1243/chrome-linux64/chrome --chrome-mode=chrome-for-testing`.
На обычной машине этот флаг не нужен.

## Проверить глазами после подстановки клипов

- Плашки с именами не перекрывают лица в кадре. Иначе в `Titles.tsx` поднять `bottom` или поменять сторону в `LOWER_THIRDS`.
- «Семья? / Клан? / Династия?» точно на словах (начала S06-03…S06-05).
- Звезда над крышей, гирлянда не закрывает лица на крупных планах. Список планов — `STRING_LIGHTS_SHOTS`.
- В клипах Flow нет случайного текста. Если есть, закрыть размытием в `ShotLayer`.
