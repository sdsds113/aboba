# ТЗ для Codex: монтаж мультика в Remotion

Нужно собрать поздравительный мультик в стиле Pixar: 16:9, 1920×1080, 24 fps, **длительность — `duration` из `timeline.json` (сейчас 136.62 с ≈ 3279 кадров)**. Все тайминги брать только из `timeline.json` и `audio/offsets.json`, в коде не хардкодить.
Видеоклипы сгенерированы в Google Flow и лежат в `clips/G01.mp4 … G25.mp4`. Монтаж, текст и графика делаются в Remotion. **Весь текст в кадре рисует только Remotion.**

## Входные данные (папка `pride-cartoon/`)

| Файл | Что это |
|---|---|
| `timeline.json` | **Источник правды.** 55 планов по порядку: `tl_in`/`tl_out` — позиция на таймлайне в секундах, `src` — клип, `clip_in` — с какой секунды клипа брать, `overlay` — какой текст или графику наложить |
| `audio/voiceover_full.mp3` | Готовая дорожка голоса на всю длину ролика: длинные паузы уже подрезаны, голос ускорен в 1.07 раза. Кладётся с 0 с, без сдвигов |
| `audio/sNN.mp3`, `audio/sNN.align.json`, `audio/offsets.json` | Голос по сценам и посимвольные тайминги ElevenLabs. Нужны, если захочется анимировать слова точно в такт голосу |
| `clips/GNN.mp4` | Клипы из Flow по 8 с. Положит пользователь |
| `assets/*.png` | Графические элементы (P01 — пустая красная стена с полкой, рамок на ней нет; E01–E15 — календарь, рамка, таблички, эмблемы, конфетти, лента, звезда, домики, гирлянда). Описание и где какой используется — в `ELEMENTS.md`, таблица «Где что используется». Все E-элементы — PNG с прозрачным фоном |
| `music.mp3` | Музыкальная подложка. Опционально, может отсутствовать |

## Структура проекта

- Composition `Birthday` (1920×1080, 24 fps, `Math.round(duration*24)` кадров).
- Для каждого планa из `timeline.json` сделать `<Sequence from={tl_in*fps} durationInFrames={dur*fps}>` и внутри `<OffthreadVideo src={src} startFrom={clip_in*fps} muted />`. Видео растягивается на весь кадр, `objectFit: cover`.
- Звук клипов из Flow **всегда заглушён**.
- Округление кадров: `Math.round(t*24)`. Конец плана = начало следующего, без дыр и нахлёстов. В `timeline.json` это уже проверено.
- `clip_in` вынести в отдельный конфиг (`overrides.json`, ключ — id плана). Тогда пользователь сможет подвинуть точку входа без правки кода.
- Если клипа ещё нет, показывать плейсхолдер: тёмный фон, id плана и описание `desc` мелким служебным текстом. Так можно смотреть черновой монтаж с голосом до того, как всё сгенерировано.

## Аудио

- Голос: `voiceover_full.mp3`, громкость 1.0.
- Музыка, если есть файл: тёплая, оркестрово-«пиксаровская». Около −14 dB, пока голоса нет, и около −24 dB под голосом. Приглушение делать плавно, за 0.3 с, по интервалам голоса из `audio/offsets.json` (`offsets` — старт сцены, `scene_durations` — длина голоса сцены). Начинается на 0 с, в конце затухает за последние 3 с.
- На S09-05 («С днём рождения!») можно поставить хлопок конфетти. Это опционально.

## Единый «кинолук» поверх всех клипов

Клипы из Flow немного различаются по цвету. Чтобы ролик выглядел как один фильм:
- лёгкая виньетка (radial-gradient, края примерно −15% яркости);
- лёгкое плёночное зерно (анимированный noise, opacity 0.04–0.06);
- одинаковая тёплая коррекция через CSS `filter`, например `saturate(1.05) contrast(1.03)`. Параметры вынести в конфиг.

## Переходы

- По умолчанию **жёсткие склейки**: это сознательный монтажный приём.
- Между сценами 5 и 6, перед S06-01, — затемнение через чёрный за 6 кадров.
- S08-07 → S08-08: матч-кат, жёсткая склейка. Ничего не добавлять.
- S09-05: в момент вспышки на последних 0.5 с плана — белая вспышка (белый слой, opacity 0 → 1 → 0 за 8 кадров). Сразу после неё стоп-кадр, см. S09-06.

## Оверлеи (поле `overlay` в `timeline.json`)

Шрифты и цвета **по нашему брендбуку**, их подставляет пользователь. Здесь вынести всё в `theme.ts`: `fontDisplay`, `fontText`, `colorAccent` (по умолчанию #E30613), `colorText` (#FFFFFF), `colorShadow`. Весь текст должен иметь мягкую тень или подложку, чтобы читаться на любом кадре. Безопасная зона — 5% от краёв.

## Планы, которые собирает только Remotion

**S06-02, стена с фото.** Фон — `assets/P01_photo_wall.png`: пустая красная стена с полкой и растением, 1672×941, растянуть на 1920×1080. **Рамок на стене нет: их ставит Remotion** из `assets/processed/E03_photo_frame.png`. Координаты пяти слотов, подписи и источники фото лежат в `photo_wall_layout.json`. Раскладка проверена на тестовом коллаже: рамки не задевают растение и полку.

Как рисовать каждый слот:
1. `k = width / 1536`. Отверстие рамки = `left + 365k, top + 312k`, размер `795k × 467k`.
2. Сначала фото (стоп-кадр из плана `photo_from`, `objectFit: cover`, лёгкая тёплая «старинность»: `sepia(0.15)` для 2014 и 2019), **потом поверх него** PNG рамки целиком (`left, top, width`).
3. Табличка `E04` по центру под рамкой (ширина 32% от `width`), на ней `label` тёмным (#3B2414), как гравировка.

Анимация: камера медленно проезжает вдоль стены слева направо (translateX 0 → −60 px, scale 1.06 → 1.10). Слоты 1–3 висят с начала плана. Слот 4 появляется на середине плана: рамка с фото опускается сверху на 120 px и покачивается вокруг гвоздя (rotate ±5° → 0 за 0.8 с, центр вращения — гвоздь, 50% ширины и 2% высоты PNG). Слот 5 в этом плане пустой, его нет.

**S09-06, финал.** Та же стена, слоты 1–4 уже висят. Последний кадр S09-05 (после белой вспышки) превращается в фотографию: уменьшается от полного кадра до отверстия слота 5 за 1 с. В конце движения вокруг фото «вырастает» рамка E03 (fade + scale 1.05 → 1), потом то же покачивание вокруг гвоздя. Под ней подпись «2026». Затем камера плавно отъезжает, показывая всю стену с историей. За 3 с до конца — финальная плашка поверх затемнения: «С днём рождения!» и строка «Твоя команда». Текст вынести в конфиг. К концу ролика затемнение в чёрный.

## Подготовка и особенности ассетов

- Перед сборкой выполнить `python3 prep_assets.py`: результат ляжет в `assets/processed/`, оригиналы не меняются.
  - `E03_photo_frame.png`: внутри отверстия обнулена остаточная прозрачность (было до 6% на ~40 тыс. пикселей). Иначе фото под рамкой было бы чуть подёрнуто дымкой.
  - `E02_calendar_page_torn.png`: оттенок подогнан под E01 (множители каналов R 1.012 / G 0.987 / B 0.927).
  - **Использовать именно `processed/` версии E02 и E03.**
- `E12` (звезда, S07-10) накладывать с `mixBlendMode: 'screen'`, иначе ореол на ночном небе выглядит как мутное персиковое облако. Позиция — над крышей дома в кадре (координаты в конфиг), лёгкая пульсация: scale 0.97 ↔ 1.03, период 1.2 с.
- `E15` (гирлянда) — по верху кадра с S08-02 до конца S09-05. Ширина PNG 2172 перекрывает кадр 1920, лёгкое покачивание rotate ±0.5°. Для лампочек тоже `screen`.
- `E10` (конфетти) — нарезать сетку 6×4 на отдельные спрайты (ячейка около 198×275 исходных пикселей, по bbox альфы) и запускать частицами 40–80 штук: падение с вращением и лёгким покачиванием по X.
- `E13`/`E14` (домики) — на финальной плашке рядом, синий слева, красный справа, между ними стрелка или плавный переход «было → стало». Высота около 300 px.
- Размеры PNG отличаются от изначально заказанных — это нормально, всё масштабируется в коде.
