## 3. Команды

```bash
git clone -b claude/beautiful-dirac-5o387h https://github.com/sdsds113/aboba.git
cd aboba/pride-cartoon/remotion
npm install
node scripts/sync.mjs          # должно найти 72 клипа
npx remotion render src/index.ts Birthday out/birthday_v3.mp4 --concurrency=4
```

Если в Linux-контейнере рендер падает на загрузке шрифтов (сертификаты прокси), запускать с полным Chromium:
`--browser-executable=<путь к chrome> --chrome-mode=chrome-for-testing`.

Посмотреть монтаж в браузере: `npx remotion studio src/index.ts`.

## 4. Проверка перед сдачей

1. `ffprobe out/birthday_v3.mp4`: 1920×1080, 24 fps, длительность **около 143.6 с**, есть аудио.
2. Стоп-кадры из середины каждого плана (`tl_in + dur/2` из `timeline.json`). Проверить:
   - таблички «2007 · Секвойя» (`S02-01`), «2014 · Восточный» (`S03-00`), «2019 · Альфа» (`S05-02`) видны и не обрезаны;
   - в зелёном домике только Нино и Маша; в синем домике Вова есть; в 2019 году нет Серёжи, Тани и Жени;
   - на стене (`S06-02`) пять подписанных рамок 2007…2025, на финальной стене (`S09-06`) добавляется «сегодня»;
   - сцена «Прайд» (`SPR-01`–`SPR-03`) идёт сразу после объятий (`S08-09`) и перед окнами в сумерках (`S09-01`);
   - нигде нет чужого текста из генераций.
3. Звук: слышны только голос и музыка, без эффектов; конец ролика не обрывается.

## 5. Что не трогать

- Тексты, озвучку, музыку и тайминги планов: всё согласовано с заказчиком.
- `clip_in` менять только если в начале или конце плана видна склейка или рывок. Точечно — через `CLIP_IN_OVERRIDES` в `remotion/src/config.ts`, например `{ "S05-02": 0.6 }`.
