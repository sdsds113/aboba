# Инструкция агенту (Codex): монтаж мультика ко дню рождения

Задача: собрать итоговый ролик **1920×1080, 24 fps, ≈136,6 с (3279 кадров)** из 25 готовых видеоклипов, голоса диктора, музыки, эффектов и графики. Весь монтаж и вся графика уже написаны в проекте Remotion. Тебе нужно **подключить клипы к монтажу, проверить, подправить и отрендерить**.

Репозиторий: `sdsds113/aboba`, ветка `claude/beautiful-dirac-5o387h`. Все пути ниже — от корня репозитория.

## 0. Что нельзя делать

- **Не генерировать и не перегенерировать видео, картинки, голос, музыку.** Если клип плох (плывут лица, лишний текст), не чинить его, а записать в отчёт: его перегенерируют отдельно.
- **Не менять тайминги планов** в `pride-cartoon/timeline.json` (они привязаны к озвучке). Меняется только `clip_in` (с какой секунды клипа брать план).
- **Не добавлять плашки с именами** — заказчик от них отказался (`LOWER_THIRDS = {}` в `pride-cartoon/remotion/src/config.ts`).
- **Никакого текста в кадре, кроме оверлеев Remotion.** Если в клипе из Kling случайно появились буквы или цифры, закрыть их размытием маской (по id плана) и записать в отчёт.

## 3. Порядок работы

1. **Подготовка.**
   ```bash
   cd pride-cartoon/remotion
   npm ci
   python3 ../prep_assets.py        # создаёт assets/processed/ (если папки нет)
   npm run sync
   npx tsc && npx eslint src
   ```
2. **Зарегистрировать клипы** (из корня репозитория):
   ```bash
   for g in G02 G04 G06 G07 G08 G09 G11 G12 G13 G14 G15 G16 G17 G18 G19 G20 G21 G22 G23 G24 G25; do
     python3 pride-cartoon/register_clip.py $g
   done
   ```
   Скрипт сам находит склейки внутри клипа. Если число найденных склеек не совпало с ожидаемым, он напишет `WARN` и разложит планы по пропорциям. **Каждый такой клип открыть и проверить глазами**, поправить `shots` в `pride-cartoon/scene_clips.json` (секунда клипа, с которой берётся план) и снова выполнить `python3 pride-cartoon/build_storyboard.py`.
3. **Подтянуть данные в проект:** `cd pride-cartoon/remotion && npm run sync`.
4. **Открыть Studio** (`npm run dev`) и просмотреть композицию `Birthday` целиком.
5. **Проверки** (раздел 4), правки.
6. **Рендер** (раздел 5).

## 4. Что проверить и подправить

- **Склейки.** Каждый план начинается с нужного кадра сцены, без смазанных лиц и без «хвоста» предыдущего плана. Сдвигать `clip_in` в `pride-cartoon/scene_clips.json`. Для G05 уже подобрано: план `S03-05` берётся с 0,84 с, потому что раньше лица на пару кадров смазываются при повороте голов.
- **Длина плана.** Если после склейки в клипе остаётся меньше секунд, чем план по таймлайну, `register_clip.py` предупредит: тогда план берётся от конца куска. Допустимо замедлить кусок на 10–15% (`playbackRate`), больше не растягивать.
- **Звук клипов.** У клипов Kling 4.0 внутри есть аудиодорожка. В монтаже она **должна быть заглушена**: `Shot.tsx` передаёт `muted`, убедиться, что звука из видео в итоге нет.
- **Календарь, план S06-01** (второй кусок клипа G09). На стене в самом клипе уже нарисован пустой календарь. Оверлей `Calendar.tsx` рисует свой календарь по центру. Проверить, что календарь из клипа не торчит из-под оверлея; если торчит, увеличить оверлей или заглушить фон сильнее (blur/затемнение). «2026» должно появиться на словах «две тысячи двадцать шестой».
- **«Семья? Клан? Династия?»** (планы S06-03, S06-04, S06-05, клип G10). Слова с эмблемами должны попадать точно на голос. Начала планов: S06-03 ≈47,4 с, S06-04 ≈48,0 с, S06-05 ≈48,6 с.
- **Звезда, план S07-10** (второй кусок клипа G18, ночной красный дом). Подобрать `STAR.x`, `STAR.y`, `STAR.size` в `config.ts` так, чтобы звезда встала над крышей дома, на настоящую звезду в клипе или рядом.
- **Гирлянда E15** висит по верху кадра на планах из `STRING_LIGHTS_SHOTS`. Проверить, что она не закрывает лица на крупных планах; при необходимости убрать план из списка.
- **Стена с фото (S06-02) и финал (S09-06).** Для рамок берутся стоп-кадры из клипов, `photo_wall_layout.json` → `photo_from`. Проверить, что подставились реальные кадры, а не заглушки, и что лица в них узнаваемы.
- **Плейсхолдеры, которые менять не надо, а только перечислить в отчёте:** годы 2014, 2019, 2024, 2026 на табличках и стене, подпись «сегодня», надпись финала «Твоя команда». Заказчик пришлёт настоящие значения.
- **Лица.** Пройти все клипы. Если в каком-то плане лицо явно чужое или «поплыло», не править: записать клип и секунды в отчёт.
- **Звук.** Баланс: диктор должен быть чётко слышен поверх музыки. Уровни в `pride-cartoon/audio/mix.json` можно менять, диктор не тише 1.5, музыка под голосом около 0.07.

## 5. Рендер

Сначала быстрый черновик 960×540, потом финал:

```bash
cd pride-cartoon/remotion
npx remotion render Birthday out/draft.mp4 --scale=0.5 --crf=26
npx remotion render Birthday out/birthday.mp4 --crf=18
```

Если рендер в облаке и Chrome Headless Shell не доверяет сертификату прокси, добавить `--browser-executable=<путь к полному Chromium> --chrome-mode=chrome-for-testing`. На обычной машине флаги не нужны. Перед финальным рендером убедиться, что в проекте нет клипов-заглушек: на экране не должно быть тёмных кадров с серыми служебными подписями (`S03-02`, описание плана и т. п.).

Итоговый файл: `pride-cartoon/remotion/out/birthday.mp4`. Длительность должна быть ≈136,6 с.

## 7. Примечание про репозиторий

Клипы (около 350 МБ) в ветку залиты не все. Надёжный способ получить их все: после `git pull` выполнить

```bash
bash pride-cartoon/download_clips.sh
```

Скрипт скачивает все 25 клипов напрямую с серверов Kling в `pride-cartoon/clips/` (уже имеющиеся пропускает). Ссылки действуют около суток после генерации (клипы сделаны 2026-11-03). Если какая-то ссылка не открылась (`ОШИБКА G??`), не продолжать с заглушкой: написать об этом в отчёте, клип достанут из истории Kling.

Перед монтажом убедиться, что в `pride-cartoon/clips/` есть все 25 файлов `G01.mp4 … G25.mp4`.
