# Раскадровка: «Редизайн короткой карточки SFACall»

Источник: Google Drive, папка **«РЕДИЗАЙН КК»**:
- `Редизайн КК.mp4`: 1920×1080, 30 fps, **2:42 (161,9 с)**, **звука нет** (дорожка AAC есть, но в ней тишина −91 dB);
- `image3.png`: схема карточки **ФЛ** (13 пунктов);
- `image2.png`: схемы карточек **ЮЛ** (18 пунктов) и **УЛ** (14 пунктов);
- `image (24).png`: поведение переключалки ФЛ/УЛ/ЮЛ и признак синхронизации.

Что это: запись экрана тестового стенда (`stacall-int-k/ufr-onespace-host-ui`) без монтажа. Оператор подключается, находит клиента и по очереди проводит курсором по элементам шапки новой карточки (ФЛ → УЛ → ЮЛ), показывая всплывающие подсказки. Склеек почти нет: один разрыв на 1:24→1:25, остальное идёт одним дублем.

Кадры лежат в `frames/` (960 px, номер_секунда.jpg).

## Что мешает ролику как презентации

1. **Нет звука и подписей.** Без схем из папки зритель не поймёт, какую иконку и зачем показывают.
2. **Мелко.** Шапка занимает около 70 px из 1080, подсказки мелкие, без зума их не прочитать.
3. **Мёртвое время** (около 35 с из 162):
   - 0:10–0:20, курсор стоит на поиске;
   - 0:33–0:38, загрузка карточки ФЛ;
   - **1:13–1:24, полный простой**;
   - 1:55–1:58, 2:27–2:33, 2:38–2:42, скелетоны и загрузки.
4. **Нет финала**: ролик обрывается на спиннере.
5. Порядок обхода иконок в ролике не совпадает с нумерацией на схемах (например, в ФЛ сначала СИМ, потом PIN, потом VOC).

## Предлагаемый монтаж (~1:30–1:45)

| Глава | Исходник | Обработка |
|---|---|---|
| Титул | 0:00–0:02 | оставить, растянуть до 3 с, плавный уход |
| Вход в сессию | 0:02–0:38 | ускорить ×3–4, вырезать 0:10–0:20 и 0:33–0:37. Подпись: «Поиск клиента → вход в сессию» |
| **ФЛ** | 0:38–1:13 | **зум на шапку** (×2–2,5 с панорамой за курсором), выноски с номером и названием по схеме `image3`. Вырезать 1:13–1:24 |
| **УЛ** | 1:25–1:50 | зум на шапку, выноски по схеме УЛ из `image2`. Отдельно выделить IMSI → переход в УКД |
| **ЮЛ** | 1:50–2:21 | ускорить скелетон 1:55–1:58. Выноски по схеме ЮЛ, акцент на панели уведомлений и списке УЛ |
| **Новая переключалка** | 2:22–2:38 | плашка «Было: по клику → Стало: по наведению» (из `image (24)`), ускорить загрузки |
| Финал | — | вместо обрыва на 2:42: стоп-кадр карточки и плашка-итог (что нового) |

Озвучка по желанию: голос через ElevenLabs (`eleven_v4`, как в других проектах репо), или только субтитры-выноски.

Технически всё делается в `montage/` (Remotion): `<Video>` с `trimBefore` и `playbackRate`, зум через `transform: scale()` на `AbsoluteFill`, выноски обычными компонентами.
