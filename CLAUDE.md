# Инструкция для облачного агента (монтаж и код)

Ты — облачный агент. **Вся творческая и кодовая работа на тебе:** сценарий, сцены, анимация, типографика, тайминги, звук, код Remotion. Рендерит локальный агент (Codex) на компьютере пользователя по `AGENTS.md`. **`AGENTS.md` написан для него, не для тебя:** его запреты («не меняй src», «только рендер») к тебе не относятся.

## Перед любой работой над роликом

1. Прочитай `REMOTION_MONTAGE_GUIDE.md` целиком, особенно блоки А–Г (как думать сценой, процесс, самопроверка). Это стандарт качества.
2. Работай по процессу из блока Б: бриф → тайминг-лист и брифы сцен → стайл-фрейм одной сцены → аниматик → полировка → самопроверка.

## Обмен файлами

- **Медиа** лежат на Google Drive: `Мой диск/Remotion/<проект>/public/` (исходники, голос, музыка, SFX, картинки). Найди файлы через коннектор Google Drive (`search_files`). Файлы до 10 МБ скачивай через коннектор, большие — `curl -L "https://drive.usercontent.google.com/download?id=<ID>&export=download&confirm=t"` в scratchpad.
- **Рендеры** локальный агент кладёт в `Мой диск/Remotion/<проект>/renders/<имя>_vNN.mp4`. Скачай нужную версию тем же способом и проверь по блоку В руководства (контактные листы, тайлы переходов, громкость).
- **Код** — в этом репозитории. Медиа в git не коммить (`.gitignore`), в том числе сгенерированные тобой звуки и картинки, если в них есть материал исходника.
- **Сгенерированные медиа** (озвучка, фоновые дорожки и т.п.) загрузить на Drive через коннектор нельзя: он принимает только мелкие файлы в base64. Собери их в zip с путями относительно `public/`, отправь пользователю через `SendUserFile` и попроси распаковать в `Мой диск/Remotion/<проект>/public/`. Оттуда их заберёт `pipeline.mjs pull`.

## Новый проект

1. Папка проекта в корне репозитория, латиницей, без пробелов: `promo-alfa/`, `gzk-q4/`. Имя совпадает с папкой на Drive `Remotion/<проект>/`.
2. Создай проект из пустого шаблона Remotion (`npx create-video@latest --yes --blank <проект>`, или скопируй структуру `montage/` и почисти `src/`). Пакеты добавляй через `npx remotion add`.
3. Добавь `<проект>/render.json` со списком композиций для финального рендера и `<проект>/README.md`: что за ролик, какие файлы должны лежать в `public/`, таймлайн.
4. Пути к медиа в коде — только `staticFile('...')` относительно `public/`, ровно как файлы лежат на Drive в `Remotion/<проект>/public/`.
5. Проверь `npx tsc --noEmit`. Если пользователь разрешил превью в облаке, отрендери стоп-кадры ключевых моментов и посмотри их сам.
6. Закоммить и запушь. В ответе пользователю напиши, что передать локальному агенту: «отрендери <проект>».

## Фирменные шрифты

Пользователь использует **фирменные шрифты со своего компьютера**. В облаке их нет, в git и на Drive их не кладём (лицензия; папка Drive открыта по ссылке). Подставляет их Codex при рендере.

- Перечисли нужные файлы в `<проект>/fonts.json`:
  ```json
  {"fonts": [
    {"family": "Brand Sans", "file": "BrandSans-Bold.otf", "weight": "700", "style": "normal"},
    {"family": "Brand Sans", "file": "BrandSans-Regular.otf", "weight": "400", "style": "normal"}
  ]}
  ```
  Точные имена файлов и семейства спроси у пользователя (или попроси Codex прислать список файлов из папки шрифтов). Не угадывай.
- Грузи шрифты в коде через `loadFont` из `@remotion/fonts` с `staticFile('fonts/<file>')`, по данным из `fonts.json`, в одном модуле `src/fonts.ts`.
- В облаке файлов нет. Для превью грузи фирменный шрифт, только если он есть в `public/fonts` (проверка через `getStaticFiles()` из `@remotion/studio`), иначе используй запасной Google-шрифт, близкий по ширине и весу. В `fontFamily` всегда ставь стек `"Brand Sans", <запасной>, sans-serif`.
- Запасной шрифт меняет ширину строк. Оставляй запас по длине строк, а итоговую вёрстку проверяй на рендере Codex, а не на облачном превью.

## Озвучка ElevenLabs

Всегда используй модель **Eleven v4** (`model_id: "eleven_v4"`), если пользователь явно не попросил другую.

## Секреты

Ключ ElevenLabs подставляет прокси в запросы к `api.elevenlabs.io` (заголовок `xi-api-key`). Ключ не запрашивай и не пиши в код или репозиторий. Для локального запуска скрипт берёт `process.env.ELEVENLABS_API_KEY`, если он задан.
