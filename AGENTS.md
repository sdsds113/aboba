# Инструкция для локального агента (рендер-станция)

> Этот файл — для локального агента на компьютере пользователя (Codex). Облачный агент Claude работает по `CLAUDE.md`, и ограничения ниже к нему не относятся.

Ты работаешь на компьютере пользователя под Windows. Твоя роль — **рендер**. Код сцен, анимации, тайминги и звук пишет облачный агент и пушит в этот репозиторий. Ты забираешь код, подкладываешь медиа с Google Drive, рендеришь и выкладываешь результат обратно на Drive.

## Чего не делать

- Не меняй код в `*/src/`, тайминги, тексты и `render.json`, если пользователь прямо не попросил. Нашёл ошибку — опиши её в отчёте, не чини сам.
- Не коммить медиа (видео, аудио, рендеры) и `remotion.local.json`.
- Не пушь в репозиторий, если пользователь не попросил.
- Не перезаписывай старые рендеры на Drive: каждая выкладка получает новую версию `_v01`, `_v02`, …

## Разовая настройка

1. Node.js 22 LTS: `winget install OpenJS.NodeJS.LTS`. Проверка: `node -v`.
2. FFmpeg (для проверок): `winget install Gyan.FFmpeg`.
3. Клонировать репозиторий, если его ещё нет:
   ```powershell
   git clone https://github.com/sdsds113/aboba.git
   ```
4. В приложении Google Drive для компьютера создать папку `Remotion` в «Мой диск». Узнать её локальный путь (обычно `G:\Мой диск\Remotion`).
5. В корне репозитория создать `remotion.local.json` (он в `.gitignore`):
   ```json
   { "driveRoot": "G:\\Мой диск\\Remotion", "fontsDir": "D:\\Шрифты" }
   ```
   `fontsDir` — папка на компьютере пользователя, где лежат фирменные шрифты (спроси у пользователя, если не знаешь). Подпапки тоже просматриваются.

## Фирменные шрифты

Шрифты пользователь берёт фирменные, они есть **только на этом компьютере**. В облаке их нет, в git и на Drive их класть нельзя (лицензия; папка Drive открыта по ссылке).

- Какие файлы нужны проекту, написано в `<проект>/fonts.json` (его пишет облачный агент): семейство, файл, вес, начертание.
- `node scripts/pipeline.mjs pull <проект>` сам находит эти файлы в `fontsDir` и в системных папках шрифтов Windows и копирует в `<проект>/public/fonts/`.
- Если файла нет, `pull` и `render` останавливаются с ошибкой. **Не подменяй шрифт похожим и не меняй `fonts.json`.** Напиши в отчёте, какого файла не хватает, и спроси пользователя, где он лежит.
- Если у пользователя шрифт другого формата или с другим именем файла (например, `.ttf` вместо `.otf`), сообщи точные имена найденных файлов в отчёте. Облачный агент поправит `fonts.json`.
- После рендера посмотри на 2–3 кадра с текстом: если буквы выглядят как Arial/Times или кириллица другим шрифтом, это ошибка подстановки — укажи в отчёте.

## Устройство папок

| Где | Что |
|---|---|
| репозиторий `<проект>/` | проект Remotion (например, `montage/`) |
| `<проект>/render.json` | список задач рендера: композиция, имя файла, флаги |
| Drive `Remotion/<проект>/public/` | медиа проекта; зеркалируется в `<проект>/public/` |
| Drive `Remotion/<проект>/renders/` | готовые рендеры с версиями |

Имя папки проекта на Drive совпадает с именем папки в репозитории.

## Рабочий цикл (по команде «отрендери <проект>»)

```powershell
cd <путь к репозиторию>
git pull
cd <проект>
npm ci
cd ..
node scripts/pipeline.mjs pull <проект>
node scripts/pipeline.mjs render <проект>
```

- `pull` копирует новые и изменённые файлы с Drive в `<проект>/public/`.
- `render` рендерит все задачи из `render.json` и кладёт каждый файл в `Remotion/<проект>/renders/` с новой версией.
- Одна композиция: `node scripts/pipeline.mjs render <проект> --only <Композиция>`.
- Если нужен быстрый черновик, пользователь скажет. Тогда добавь к команде рендера флаги `--scale=0.5 --crf=28` вручную через `npx remotion render` и выложи через `node scripts/pipeline.mjs publish <проект> out/<файл>`.

Если Remotion не может скачать Chrome Headless Shell, укажи установленный Chrome: добавь `--browser-executable="C:\Program Files\Google\Chrome\Application\chrome.exe"`.

## Проверка после рендера

```powershell
ffprobe -v error -show_entries format=duration:stream=codec_name,width,height,r_frame_rate -of compact <файл>
ffmpeg -i <файл> -af ebur128=peak=true -f null - 2>&1 | Select-Object -Last 12
```

Убедись, что длительность и разрешение совпадают с композицией, а звук есть.

## Отчёт пользователю

Коротко, чтобы пользователь мог переслать его облачному агенту:

```
Проект: montage
Коммит: <git rev-parse --short HEAD>
Рендеры: edit_v03.mp4 — 47,3 с, 1920×1080, 30 fps, −15,2 LUFS, рендер 4 мин 10 с
Ошибки/предупреждения: <нет | текст ошибки целиком>
Замечания: <например, «в public нет music/track.mp3, на Drive его тоже нет»>
```

При ошибке рендера приложи последние 40 строк лога и не пытайся переписать код сцен.
