# Ачивки сервиса: точечная корректировка ролика

Исходник «АЧИВКИ(8).mp4»: 1920×1080, 60 fps, 5236 кадров (87,27 с). Монтаж, мемы, переходы, музыка и длительность не меняются. Меняется только следующее.

1. **Экран условий.** Вместо старых порогов «1 / 10 / 30 благодарностей» показываются актуальные условия по направлениям (`public/references/current-conditions.png`):
   - **21,90–32,77 с:** экран заменён целиком. Это та же страница Alfa People (шапка, меню, заголовок и картинка с сердцами взяты из кадра исходника), только с новым текстом. Камера наезжает и переводит фокус в такт словам: «благодарности клиентов» → «топ по положительным оценкам» → «зачтённые WOW-диалоги» → общий вид статьи → строки «Мастер сервиса».
   - **78,67–80,58 с:** блок со старыми условиями на странице закрыт новым. Накладка обрезается по краю зелёной шторки покадрово.
2. **Дикторский текст.** Универсальные пороги убраны. Теперь звучит: «Условия зависят от направления: благодарности клиентов, топ по положительным оценкам или зачтённые вау-диалоги. Точные условия — в описании ачивки». Подводка к шутке: «Ну а стать мастером сервиса — это уже на уровне, когда…». Остальной текст сохранён.
3. **Озвучка.** Вся речь диктора заново сгенерирована в ElevenLabs голосом Nikolay (`eleven_multilingual_v2`), 19 реплик (`public/generated/voice/`). Каждая реплика стоит на месте исходной, а скорость подобрана так, чтобы речь укладывалась в видеоряд. Голос старого диктора вырезан нейросетью MDX-Net (UVR Inst HQ3). Музыка, звуки и реплики мемов взяты из исходника (`public/generated/bed.mp3`). Громкость нового голоса выровнена по старому, общий уровень ролика остался прежним (около −23,5 LUFS).
4. **Субтитры.** Старые вшитые плашки диктора стёрты из видео: `prepare.mjs`, ffmpeg `delogo` по `src/data/cleanup.json`. Плашка мема «А чё так можно было что ли?» оставлена исходной. Новые субтитры набраны Styrene A Bold в том же виде, тайминг взят из посимвольной разметки озвучки.

## Рендер

Из корня репозитория:

```powershell
node scripts/pipeline.mjs pull achievements
node scripts/pipeline.mjs render achievements
```

`render` сам запускает `prepare.mjs`. Первый запуск дольше на 1–2 минуты: ffmpeg перекодирует исходник без старых субтитров.

## Что проверить на рендере

- **Шрифты.** В субтитрах и на экране условий должен стоять Styrene, а не Inter. Inter означает, что шрифт не подставился.
- **21,90 и 32,77 с.** Склейки на экран условий и с него без вспышек.
- **79–80,6 с.** Новые условия на странице, при наезде шторки не видно ни старого текста, ни белого прямоугольника поверх зелёного.
- **Субтитры.** Под новыми плашками не проступают старые. Над мемом на 37,7–39,4 с плашка исходная.

## Как править

- **Текст и тайминг озвучки** лежат в `src/data/voiceover-script.json` (реплики, окна, скорость). Перегенерация: `tools/tts.py`, затем `tools/gen_data.py`, он обновит `voice.json` и `subtitles.json`.
- **Громкость голоса:** `VOICE_VOLUME` в `src/timeline.ts`.
- **Условия на экране:** `LINES` в `src/components/ConditionsArticle.tsx`.
- **Камера экрана условий:** `SHOTS` в `src/components/ConditionsScreen.tsx`.
- **Зоны стирания старых субтитров:** `src/data/cleanup.json`, после правки перезапустить `node prepare.mjs`.
